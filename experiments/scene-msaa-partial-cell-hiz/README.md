# scene-msaa-partial-cell-hiz

Status: Finding / not adopted.

Three variants matched physical sample depths in 108 paired views. More occlusion decisions did not change successful depth writes. Bistro frame time increased by 1.748%, 2.960% and 0.658%; Sponza increased by 7.590%, 12.636% and 12.074%. An apparent 20.232% BMW gain in V2 came from an anomalously slow control and is not an accepted gain.

The [original experiment and receipts](https://github.com/Weichwolf/softgl/blob/262f573c0cc0b664cb1be5dd4f0e9533bea5037b/experiments/scene-msaa-partial-cell-hiz/README.md) are preserved in Git at `262f573c0cc0b664cb1be5dd4f0e9533bea5037b`. The rejected implementation is not part of the renderer.
