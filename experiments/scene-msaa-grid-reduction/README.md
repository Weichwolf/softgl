# scene-msaa-grid-reduction

Status: Finding / not adopted.

The applicable case represented only 0.014% of Bistro and 1.386% of Sponza general four-sample setups. Arithmetic matched in 108 native/WASM views, but the tiny eligible fraction left no meaningful frame-time opportunity.
